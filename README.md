# Git & GitHub Final Task

A practical project demonstrating the use of Git and GitHub for version control and repository management.

## About the Project

This project was created as a final practical task for the Git and GitHub course.

The goal of the project was to demonstrate the ability to work with Git repositories, track changes, manage files, and use GitHub as a remote repository platform.

## Skills Demonstrated

- Creating and managing Git repositories
- Tracking files with Git
- Creating commits
- Working with branches
- Using `.gitignore`
- Connecting local and remote repositories
- Pushing changes to GitHub
- Working with GitHub repositories
- Understanding the basic Git and GitHub workflow

## Project Structure

- `.gitignore` - Defines files and folders excluded from version control
- `github_profile_url.txt` - GitHub profile information
- `student_note_Bajrama_Veladzic.txt` - Student task notes

## Technologies & Tools

- Git
- GitHub
- Command Line

## Purpose

This repository demonstrates practical knowledge of version control and the ability to use Git and GitHub as part of a software development workflow.
